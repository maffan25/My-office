# Tema baru MyOffice (Playful)
- Semua tampilan baru ada di `playful.css` (dimuat paling akhir, menimpa tema lama).
- Beranda: sapaan "Hai, {nama} 👋🏻", kartu pink, ringkasan krem, kartu teal, tile "Menu saya", dock gelap.
- Sapaan mengikuti Nama panggilan di Settings > Profil (default: Sobat).
- Setelah mengubah file sumber, jalankan `python3 build.py` untuk membuat ulang index.html, app.css, app.js.
